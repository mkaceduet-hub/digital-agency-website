# VYORA — Digital Agency Website

A modern, responsive digital agency website concept built with HTML, CSS and JavaScript. The design focuses on creative direction, clear service presentation, selected project concepts and a simple contact experience.

## Live Demo

After enabling GitHub Pages, the website will be available at:

https://mkaceduet-hub.github.io/digital-agency-website/

## Features

- Modern agency-inspired visual design
- Responsive layout for desktop, tablet and mobile
- Mobile navigation menu
- About, services, work, process and contact sections
- Lightweight JavaScript interactions
- Accessible navigation labels and reduced-motion support
- SEO-friendly page title and description

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Project Files

- `index.html` — website structure and content
- `style.css` — layout, visual design and responsive styles
- `script.js` — mobile menu and demo form interaction

## Run Locally

1. Download or clone this repository.
2. Open the project folder in Sublime Text.
3. Open `index.html` in your browser to preview the website.

## Important Notes

VYORA is a fictional digital agency and this website is an original portfolio concept. It is not a real agency website or commissioned client project.

The contact form is front-end demonstration only. It does not send, store or process messages. The displayed email address `hello@example.com` is a placeholder and should be replaced before any real-world use.

The Google Fonts connection requires an internet connection.
